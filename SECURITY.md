# Security and Responsible Disclosure

This repository is for reliability investigation, not vulnerability exploitation.

Do not post credentials, authentication/session material, private endpoints containing identifiers, personal data, or information that would enable access to another user's account or conversations.

Do not intentionally bypass rate limits, safeguards or access controls. Do not use automated traffic generation to test this investigation.

If a contribution appears to disclose a security vulnerability, exploit path, secret or sensitive private data, do not post the details publicly. Use the affected vendor's appropriate private security/support reporting channel instead.

The repository may discuss client-observable implementation behaviour only to the extent needed to understand reliability symptoms and possible failure mechanisms. Root-cause claims require evidence.
