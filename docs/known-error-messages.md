# Known Error Messages and Search Phrases

This page is a discovery aid, not a claim that every phrase below represents the same failure mechanism.

Users investigating related problems may search for phrases such as:

- `ChatGPT conversations not loading`
- `ChatGPT conversation not loading`
- `ChatGPT history not loading`
- `ChatGPT old chats not opening`
- `ChatGPT existing conversation won't open`
- `Couldn't load this ChatGPT conversation`
- `Unable to load conversation`
- `Too many requests`
- `ChatGPT Too many requests`
- `ChatGPT HTTP 429`
- `conversation 429`
- `conversation history 429`
- `Retry-After`
- `conversation retrieval failed`
- `conversation refresh failed`
- `Couldn't refresh messages`
- `Resume stream unavailable`
- `chat visible in search but won't open`
- `conversation works on web but not desktop`
- `conversation works on one device but not another`
- `repeated conversation requests`
- `conversation recovery loop`
- `conversation refetch`

## Interpretation boundary

Matching wording is only a discovery signal. Classify evidence using the repository's S0-S3 taxonomy and H0-H12 framework before inferring technical equivalence.
