# GitHub in 60 Seconds — for Non-Technical Visitors

You do not need to learn Git or programming. The links below take you directly to the right place.

## Read help

**[Open Community Help](../HELP.md)** → choose the symptom that looks most like yours.

**[See the 10-second status](../STATUS.md)** → check what is reported, what is known, whether a workaround exists, and where to ask for help.

## Ask the community

**[Open Discussions](https://github.com/gmot-bot/chatgpt-conversation-429-investigation/discussions)** → find the closest existing topic → `Comment` / `Reply`.

Start here if useful:

- **[Affected users / conversation not loading](https://github.com/gmot-bot/chatgpt-conversation-429-investigation/discussions/1)**
- **[HTTP 429 / technical evidence](https://github.com/gmot-bot/chatgpt-conversation-429-investigation/discussions/2)**
- **[Safe troubleshooting and mitigations](https://github.com/gmot-bot/chatgpt-conversation-429-investigation/discussions/3)**
- **[Hypotheses and engineering analysis](https://github.com/gmot-bot/chatgpt-conversation-429-investigation/discussions/4)**

Use ordinary language. You do not need logs to ask for help.

## Ask a new question

**[Start a new Discussion](https://github.com/gmot-bot/chatgpt-conversation-429-investigation/discussions/new/choose)** → choose the closest category → describe what you see → remove private information → publish.

Before opening a new topic, search existing Discussions so the community can keep one useful answer in one place.

## Report a structured observation

**[Open a new Issue / report form](https://github.com/gmot-bot/chatgpt-conversation-429-investigation/issues/new/choose)** → choose **Community help question**, **Simple problem report**, or the technical reproduction form.

Also useful: **[Known Problems](known-problems.md)** · **[Error Library](error-library.md)** · **[Workarounds & Solutions](workarounds-and-solutions.md)** · **[Other people are seeing this](people-are-seeing-this.md)** · **[Latest changes](latest-changes.md)**.

## Found an answer?

In a Q&A Discussion, an accepted answer can be highlighted so later visitors find it quickly. If a response solved or clarified your question, mark it as the answer when GitHub offers that option.

## About opening links in a new tab/window

GitHub controls link behaviour in rendered repository Markdown. This project therefore uses normal accessible links rather than JavaScript or forced pop-ups. On mobile/desktop, use your browser/GitHub app's **open in new tab/window** action when you want to keep this guide open.

## Never paste

Passwords | tokens | cookies | email addresses | account IDs | conversation IDs | request IDs | IP addresses | precise location | private chat text | raw HAR files.
