# v0.4.4 — Community Status, Navigation & Evidence Dashboard Baseline

V4.3 makes the community state readable in seconds. V4.4 adds a deliberately gated evidence-dashboard baseline without premature charts or invented counts.

## V4.3
- Added a 10-second `STATUS.md` entry point.
- Added Known Problems / Recently Reported.
- Added browse-by-error and browse-by-platform indexes.
- Added controlled status-update protocol.
- Added explicit official OpenAI status-context rules.

## V4.4
- Added Evidence Dashboard schema and publication gate.
- Kept numerical tables gated until reports are normalized, deduplicated and privacy-reviewed.
- Explicitly prohibits interpreting repository frequency as global prevalence.

## Unchanged
- Root cause remains **NOT DETERMINED**.
- Causal investigation remains `STANDBY_EXTERNAL / MONITORING` unless a substantive delta appears.
- No deliberate error generation, repeated retries, rate-limit bypass, precise geography, private identifiers, force-push or history rewrite.
