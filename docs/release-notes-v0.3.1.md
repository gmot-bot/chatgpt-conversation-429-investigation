# v0.3.1 — Community Surface

Community participation is now live and routed by evidence maturity.

## Added

- Four seeded GitHub Discussions: affected-user start point, technical HTTP 429 evidence, safe troubleshooting, and H0-H12 engineering analysis.
- Direct community entry points from the README.
- Updated Discussions guide with live links, Issue/Discussion routing and privacy/safety gates.

## Preserved boundaries

- Root cause remains **NOT DETERMINED**.
- No deliberate failure generation, repeated retries, reconnect storms or rate-limit bypass.
- No private identifiers, precise locations, private HAR material or support correspondence were published.
- No claim of global outage/overload or universal mechanism.

## Deferred human gates

- Repository licence selection remains a rights decision and is not imposed by this release.
- Uploading/changing the GitHub social-preview image remains a repository-settings/UI action; the public-safe specification exists in `docs/social-preview-spec.md`.
- External backlinks/comments on third-party issues are not posted automatically to avoid unsolicited promotion/spam.
