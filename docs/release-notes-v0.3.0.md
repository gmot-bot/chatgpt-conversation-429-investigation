# v0.3.0 — Evidence, Engineering and Discoverability Baseline

This release establishes a stable public documentation baseline for the independent investigation.

## Included

- S0-S3 evidence taxonomy and independent-public-report matrix.
- H0-H12 competing hypothesis framework.
- Falsification and conditional solution matrices.
- Engineering decision tree and observability wishlist.
- Privacy-preserving evidence and contribution guidance.
- START HERE, safe troubleshooting, FAQ, glossary and known-error/search-phrase index.
- Simple and technical Issue-reporting paths.
- Discoverability V3 public-report triage and Discussions guidance.

## Epistemic boundary

**ROOT CAUSE: NOT DETERMINED.** This release does not claim a global outage, global overload, one universal failure mechanism, or a specific limiter implementation.

## Safety

Do not generate failures, automated retries, parallel load, reconnect storms or rate-limit bypass attempts. Prefer passive evidence, independent public reports and vendor/server telemetry.
