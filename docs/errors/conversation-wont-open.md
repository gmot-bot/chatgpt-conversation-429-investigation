# Conversation Will Not Open

**Symptom:** an existing ChatGPT conversation is present but opening it fails, hangs, or returns an error.

**What we know:** this symptom appears in independent public reports. The same symptom can arise from different technical outcomes, so it is not enough to identify root cause.

**Safe steps:** stop repeated retries; record the exact error wording; allow any indicated cooldown to expire; check [Safe troubleshooting](../../TROUBLESHOOTING.md).

**Avoid:** repeated refresh loops, automated retries, deleting data as an experiment, or publishing private conversation information.

**Community:** [compare experiences / ask for help](https://github.com/gmot-bot/chatgpt-conversation-429-investigation/discussions/1).
