# Chat History Is Not Loading

History-loading failures are a user-visible symptom, not a single diagnosis. Reviewed public evidence includes both rate-limited retrieval and non-429 failure modes.

**Safe steps:** record the exact message; stop repeated refreshes; wait normally; use [Safe troubleshooting](../../TROUBLESHOOTING.md).

**Do not assume:** global outage, account damage, HTTP 429, or one common root cause without direct evidence.

**Community:** [start-here discussion](https://github.com/gmot-bot/chatgpt-conversation-429-investigation/discussions/1).
