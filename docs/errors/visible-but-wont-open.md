# Conversation Is Visible but Will Not Open

A conversation can remain visible/searchable while retrieval or rendering fails. Visibility therefore does not guarantee successful conversation-body retrieval.

Record whether the chat remains visible, the exact error wording, and whether normal waiting changed the outcome. Do not repeatedly retry to generate evidence.

This observation is useful as application behaviour (S1), but it does not identify the underlying cause.
