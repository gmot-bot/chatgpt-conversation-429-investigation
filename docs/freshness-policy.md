# Freshness & Status Review Policy

A community status page is useful only when readers can distinguish current review state from continuous monitoring.

## Freshness labels

- `REVIEWED` — inputs were checked at the displayed project review date.
- `NEW INPUT PENDING REVIEW` — a known new contribution has not completed triage.
- `STALE` — the project-defined review interval elapsed without a new bounded review.
- `EXTERNAL MONITORING` — causal progress depends on vendor/server or independent external evidence.

## What “Last reviewed” means

It means the project checked the defined public inputs at that checkpoint. It does **not** mean no newer ChatGPT incident exists, that OpenAI has no newer status notice, or that the repository is continuously monitored.

## Update triggers

Review status when there is a new repository contribution, new discriminating independent public evidence, a relevant official status notice, a workaround candidate, a privacy incident, or a frozen claim challenged by evidence.

## Material update rule

Do not bump a problem's state merely to appear active. No evidence delta -> no epistemic status promotion.
