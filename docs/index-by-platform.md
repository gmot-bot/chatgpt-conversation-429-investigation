# Browse by Platform

Platform is a **routing and comparison field**, not proof of cause. A problem appearing on two platforms does not establish a common backend mechanism.

| Platform family | What to record safely | Where to start |
|---|---|---|
| Web browser | symptom/error wording; whether conversation remains visible; normal wait outcome | [Community Help](../HELP.md) |
| Windows desktop | same non-identifying fields; app family only | [Community Help](../HELP.md) |
| macOS desktop | same non-identifying fields; app family only | [Community Help](../HELP.md) |
| Android | same fields; distinguish app from web when known | [Community Help](../HELP.md) |
| iOS / iPadOS | same fields; distinguish app from web when known | [Community Help](../HELP.md) |
| Work / Project surface | symptom and broad surface only; do not expose workspace/project identifiers | [Community Help](../HELP.md) |
| Other / unknown | keep `UNKNOWN`; do not infer | [Community Help](../HELP.md) |

## Why this index exists

When enough deduplicated reports exist, platform-family counts may be shown in the Evidence Dashboard. They will describe this repository's submitted sample only, never platform-wide or ChatGPT-wide prevalence.
