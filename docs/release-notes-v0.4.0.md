# v0.4.0 — Community Help & Error Library

V4 adds a complementary non-technical help layer while preserving the technical investigation and its evidence standards.

## Added
- Community Help landing page and symptom/problem finder.
- Error & Problem Library with explicit evidence/status vocabulary.
- Individual pages for six common symptom/error families.
- “What we know / do not know” evidence-boundary page.
- Beginner guide to GitHub Discussions and reporting.
- Community triage protocol and duplicate/evidence-promotion rules.
- Community-help Issue form for ordinary-language questions.

## Unchanged
- Causal 429 investigation remains `STANDBY_EXTERNAL / MONITORING`.
- Root cause remains **NOT DETERMINED**.
- No deliberate failure generation, repeated retry/load testing, geography change, repository rename or history rewrite.
