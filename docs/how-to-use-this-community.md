# How to Use This Community if You Are New to GitHub

You can read this public repository and its help pages without understanding Git or software development.

## I only want help

1. Open [Community Help](../HELP.md).
2. Choose the symptom closest to what you see.
3. Read the safe steps and the privacy warning.
4. Open the linked Discussion if you want to compare your experience with other users.

## I want to ask a question

Sign in to a GitHub account, open the repository's Discussions area, choose the closest existing discussion, and describe the symptom in ordinary language. Exact error wording is useful, but remove private content.

## I want to report a problem

Use **Simple problem report**. You will be asked what happened, where it happened, whether the conversation was old/new, whether it remained visible, and whether normal waiting changed the outcome. Technical diagnostics are optional.

## I have technical evidence

Use **Independent reproduction** only when you already have technical evidence obtained safely. Do not create extra traffic merely to fill in the form.

## Discussion or Issue?

- **Discussion:** question, experience, possible workaround, hypothesis, or “is anyone else seeing this?”
- **Simple problem report:** structured non-technical observation that may be useful to compare.
- **Independent reproduction:** stronger technical evidence suitable for S0-S3 classification.

## Privacy

Do not post credentials, cookies, tokens, emails, unique account/conversation/request identifiers, IP addresses, precise locations, private conversations, private support correspondence or raw unsanitized HAR files.
