# Alternative Explanations

The investigation intentionally preserves competing explanations.

Possible classes include server-side account/history state, a rate-limit bucket or limiter whose scope is not visible client-side, client recovery/refetch behaviour that exposes rather than causes an independent server-side condition, request amplification or insufficient coalescing, and a hybrid interaction involving more than one layer.

The evidence currently weakens explanations that rely solely on one local cache/profile or one home-network path, but it does not justify eliminating all client/environment contributions.

No alternative listed here is promoted to root cause without discriminating evidence.
