# Discussions Guide

GitHub Discussions is enabled for this repository. Discussions are for questions, related experiences, hypothesis analysis and evidence interpretation that do not yet meet the structured Issue evidence gate.

## Live community entry points

1. [Are your ChatGPT conversations failing to load? Start here](https://github.com/gmot-bot/chatgpt-conversation-429-investigation/discussions/1) — non-technical experiences and symptom reports.
2. [HTTP 429 / Too Many Requests — technical evidence](https://github.com/gmot-bot/chatgpt-conversation-429-investigation/discussions/2) — directly observed 429, Retry-After and sanitized request/recovery evidence.
3. [Safe troubleshooting and mitigations](https://github.com/gmot-bot/chatgpt-conversation-429-investigation/discussions/3) — bounded, low-risk troubleshooting only.
4. [Hypotheses and engineering analysis](https://github.com/gmot-bot/chatgpt-conversation-429-investigation/discussions/4) — H0-H12, falsifiers, alternative explanations and observability needs.

## Participation routing

- Use **Discussions** when the observation is exploratory, non-technical, a question, or a hypothesis.
- Use the **Simple problem report** Issue template for a structured but low-barrier report.
- Use the **Independent reproduction** Issue template for technical evidence that can be classified S0-S3.
- Link to an existing discussion/report rather than duplicating the same observation.

## Privacy and safety gate

Never post account/conversation/request IDs, IP addresses, cookies, tokens, email addresses, precise locations, private support correspondence, private HAR files or unrelated conversation content.

Do not repeatedly refresh, automate retries, create reconnect storms, generate load or bypass rate limits to obtain evidence. Root cause remains **NOT DETERMINED**.
