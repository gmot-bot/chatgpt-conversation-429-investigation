# Discussions Guide

GitHub Discussions is enabled for this repository. Discussions are for questions, related experiences, hypothesis analysis and evidence interpretation that do not yet meet the structured Issue evidence gate.

## Suggested pinned/seeding discussions

### 1. Are your ChatGPT conversations failing to load? Start here
Use this for non-technical experiences. Include the exact error wording, coarse platform/app family, whether the chat remained visible/searchable, and whether waiting naturally restored access. Do not post private identifiers or chat content.

### 2. HTTP 429 / Too Many Requests — technical evidence
Use this for directly observed conversation/history HTTP 429, `Retry-After`, refetch/retry/recovery observations and sanitized request-sequence evidence. Separate direct observation from inference.

### 3. Safe troubleshooting and mitigations
Share only bounded, low-risk mitigations. Do not recommend repeated refresh, automated retry, reconnect storms, load generation or rate-limit bypass.

### 4. Hypotheses and engineering analysis
Discuss H0-H12, falsifiers, alternative explanations and observability needs. Similar UI symptoms do not establish one root cause.

## Privacy gate

Never post account/conversation/request IDs, IP addresses, cookies, tokens, email addresses, precise locations, private support correspondence, private HAR files or unrelated conversation content.
