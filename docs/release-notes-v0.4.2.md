# v0.4.2 — Community UX, Knowledge Base & Intelligence Baseline

This release expands the V4 help surface for mobile/non-technical visitors and establishes a privacy-preserving Community Intelligence schema.

## V4.1
- Community Help Centre with one-choice routing.
- Did This Help feedback vocabulary.
- Workarounds & Solutions with explicit fix-confidence states.
- Other People Are Seeing This index and “me too” deduplication policy.
- GitHub in 60 Seconds guide.
- Periodic community triage checklist.
- Discussion forms prepared for General and Q&A categories.

## V4.2
- Community Intelligence schema for aggregate, non-identifying observations.
- Explicit `community frequency != global prevalence` rule.
- Unknown-preserving normalization and deduplication safeguards.
- Community/official/root-cause status separation.

## Frozen
The causal investigation remains `STANDBY_EXTERNAL / MONITORING`; root cause remains **NOT DETERMINED**.
