# v0.4.5 — Community Operations & Contribution Pipeline

V4.5 operationalizes the community layer without automating causal conclusions.

## Added

- bounded contribution pipeline;
- public-safe triage ledger schema;
- conservative deduplication protocol;
- freshness/status review semantics;
- candidate-only automatic promotion rules;
- Latest Community Changes page;
- aggregate-readiness gate;
- machine-readable aggregate JSON schema, example and local validator.

## Deliberately not added

- no invented historical aggregate counts;
- no automatic causal or H0-H12 conclusions;
- no global-prevalence claims;
- no charts before the statistical gate;
- no deliberate ChatGPT failure generation.

Causal investigation remains `STANDBY_EXTERNAL / MONITORING`; root cause remains **NOT DETERMINED**.
