# Social Preview Specification

Recommended GitHub social-preview artwork. This is a specification only; uploading/changing repository imagery is a separate UI action.

## Text

**ChatGPT Conversation Loading Failures**

`HTTP 429 · Too Many Requests · History Retrieval · Retry/Recovery`

**Independent evidence-led investigation**

`Root cause: NOT DETERMINED`

## Design constraints

- 1280 × 640 px target canvas.
- High contrast, large text, readable when reduced.
- No OpenAI logo, trademark-styled imitation, screenshots containing private data, personal identifiers or geographic information.
- Neutral technical visual language: request/response nodes, timeline, or abstract network path.
- Avoid alarmist words such as `global outage`, `mass failure` or `confirmed bug`.
- Keep the repository slug small but readable: `gmot-bot/chatgpt-conversation-429-investigation`.

## Alt text

Social preview for an independent investigation of ChatGPT conversation-loading failures, HTTP 429 rate limiting, history retrieval and retry/recovery behaviour; root cause not determined.
