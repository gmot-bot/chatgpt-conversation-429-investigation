# Official OpenAI Status — How to Use It Here

Official OpenAI status information is the authoritative source for incidents OpenAI acknowledges. This project links to it as **context**, not as an automatic explanation for a community report.

## Current rule

1. Check the official status page for acknowledged incidents.
2. Compare the affected component, time window and described symptom at a coarse level.
3. Record `POSSIBLY RELATED` only as context unless stronger evidence connects the report.
4. Never infer that a closed official incident resolved every similar community report.
5. Never infer a global outage from community frequency.

Official status: https://status.openai.com/

## Recent context relevant to conversation-error interpretation

The official history has included resolved incidents affecting ChatGPT conversations and other ChatGPT surfaces. Those incidents demonstrate that service-side incidents do occur, but each incident has its own stated scope. They do not establish the root cause of this repository's broader evidence set.
